# Launcher 🚀

This program is a central launcher that bundles multiple utilities together. 

> 📝 **Note:** This launcher supports a limited set of commands. Please check `commands.txt` for the full list of available options


## 🛠️ Requirements

Before running the program, ensure you have the following installed:

1. **Visual Studio Code** (or your preferred IDE)
2. **Python 3.11 or 3.12** 
   * ⚠️ *Note: Python versions 3.13 and above are currently not supported.*
3) If you have a new version just know that older versions have more library suppot so **3.12 is currently better than the latest ones** :D

## 🚀 How To Run

Simply open your file manager and double-click on **`MAIN_PROGRAM.py`**. That's it!

## 🎵 How to Add & Play Songs

1. Open the folder named: `"This Should Be the place where your Music should Be"`.
2. Drop your `.mp3` files into that folder.
3. In the launcher, type `play <songname>` to enjoy your music!

## 📦 Dependencies & Libraries

* When you launch the app, a setup window/terminal may pop up to download required libraries like `pygame` and `requests`. 
* **Don't worry:** This is completely safe and required to make the program function. It will not harm your computer.
